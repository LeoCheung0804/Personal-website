Robo-Tapper Facade Inspection Robot

Project Overview

The Robo-Tapper system is a cable robot designed for high-rise building inspections. This cable robot system minimizes the hazards and expenses linked to traditional human or drone inspections by automating the hammer testing process with an AI-powered algorithm that ensures precise defect detection.

Responsibilities

  • Led the design and development of mobile autonomous robot for AI-based façade inspections
  • Passed field-testing phase and completed over 12 commercial Façade Inspections within one year, Generated over 1.5 million HKD in revenue
  • Optimised for the overall structure, reduced weight while enhancing the system's stability
  • Designed layouts and manufactured the Electric and Control boxes for the robot
  • Developed ROS nodes and API for UI, robot navigation and signal processing using C++ and Python
  • Integrated Laser sensors, IMU, LIDAR and Computer Vision for navigation and defects detection
  • Experienced in industrial safety compliance, including Form 5 certification under the Factories and Industrial Undertakings Regulations, in collaboration with a Registered Professional Engineer
