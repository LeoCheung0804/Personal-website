Borderless Lab 365: Remote STEM Laboratory

Project Overview

Borderless Lab 365 is a browser-based remote laboratory that lets secondary students control real STEM experiments from anywhere. The physical setups are hosted and maintained by PolyU's Department of Applied Physics.

The platform relays user commands to laboratory hardware through PolyU's server, then returns live video and sensor data so students can observe each experiment as it runs.
